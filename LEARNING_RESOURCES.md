## How to use this library

Use a resource when a concept or tool is blocking your progress. The course notebooks, daily guides, pinned package versions and assessment rules remain the authoritative implementation source.

The selected videos are in English. Use available captions when helpful. Older videos may show a different interface; follow the current course guides for exact clicks and files.

## Resource verification notes | ملاحظات التحقق من الموارد

<table>
<tr>
<td width="50%" valign="top" dir="ltr">

The course resource register stores the recorded video title, channel, duration and public availability check. Availability, captions and regional access can change after verification.

Automated link states:

- `PASS`: the checker confirmed availability.
- `METADATA_ONLY`: public metadata was confirmed, but playback was not confirmed from the checker environment.
- `UNVERIFIED`: manual review is required.
- `BROKEN`: the link could not be found.

These link states do not affect student grades.

</td>
<td width="50%" valign="top" dir="rtl">

يحفظ سجل موارد الدورة عنوان الفيديو والقناة والمدة ونتيجة فحص الإتاحة العامة. وقد تتغير الإتاحة والترجمة والوصول الإقليمي بعد التحقق.

حالات فحص الروابط:

- `PASS`: أكد الفاحص الإتاحة.
- `METADATA_ONLY`: تأكدت البيانات العامة، لكن التشغيل لم يُؤكد من بيئة الفحص.
- `UNVERIFIED`: يحتاج إلى مراجعة يدوية.
- `BROKEN`: لم يُعثر على الرابط.

لا تؤثر حالات الروابط في درجات المتدربين.
