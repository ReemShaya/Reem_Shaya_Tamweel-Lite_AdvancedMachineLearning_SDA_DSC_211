# أدوات مساعدة لتشغيل مشروعك

تنفذ دفاتر الاستعداد والأيام الخمسة الإعداد والفحوص تلقائيًا. لا تحتاج إلى استخدام الطرفية.

- `setup_colab.py`: يجهز المساحة ويثبت الإصدارات المطلوبة ويتحقق من بصمات الملفات.
- `data_checks.py`: يفحص الأعمدة والقيم والفصل بين ملفات التدريب والتحدي.
- `readiness_checks.py`: يجرب توافق المكتبات على عينة تعليمية صغيرة مستقلة عن المشروع.
- `generate_synthetic_data.py`: يعيد إنشاء التدريب ونسخة التسرب بالبذرة المعلنة؛ لا ينشئ بيانات التحدي أو إجاباتها.

`day1_lab.py`: افحص خطوات التقسيم، والتعويض داخل التدريب، واختيار عدد الأشجار، وإعادة التدريب وحساب المقاييس. لا تختار الدوال مرشحك ولا تكتب تفسيرك.

للتوسع الاختياري محليًا، من جذر مشروعك:

```bash
python scripts/generate_synthetic_data.py --output regenerated_data
python -m unittest discover -s tests -v
```

The notebook handles setup for you. These helpers validate inputs and software compatibility; they do not replace your model comparisons or written reasoning.

`day2_validation.py`: تدقيق زمن إتاحة الخصائص، إزالة التكرار، تقسيم الزمن والعملاء ونضج90 يومًا، معالجة وإيقاف مبكر داخل التدريب، بحثOptuna محدود، وتقارير الطيات وتغطيةOOF. الضوابط المتسربة موسومة وغير صالحة لاتخاذ قرار. اقرأ الدوال لتبرر منهجك، ثم اكتب تفسيرك بنفسك.

`day3_decision.py`: تدريب أوزان الفئة وإعادة العينات داخل الطية فقط، إنشاءOOF، فحص كل قواعد العتبة مع حفظ التعادل والسعة لكل فترة، وتدقيق معدل الإنذار الخاطئ بمقامه. القيم بوحدات خسارة تعليمية؛ الأمثلة موسومة وممنوعة في وضع التقييم.

`day4_trust.py`: أربعة أدوار منفصلة بالزمن والعملاء للتدريب والمعايرة والسياسة والتقييم. يراجع وحداتSHAP وجمع الإسهامات، ويحسب أهمية التبديل والحاويات وbootstrap للعملاء واتحاد منطقة المراجعة. المثال المحفوظ مقيد ببصمة النموذج وممنوع في وضع التقييم.

`day5_final.py`: OOF أمامي متداخل لتعلم الأوزان والتجميع، مقارنة الجدوى، معايرة محجوزة وتصدير النموذج. `inference.py` يعيد المعرف والاحتمال؛ تطبق سياسة السعة على الدفعة كاملة بعد جمع التنبؤات. `day5_delivery.py` يفحص الملفات والبصمات ويجمع أدلتك دون منح درجات. `replay_final.py` يعيد التنبؤ المحفوظ، و`rebuild_final.py` يعيد التدريب من البيانات والإعدادات المسجلة.
