# تسليمك النهائي

راجع [دليل التسليم](../SUBMISSION_GUIDE.md). احفظ الملفات النهائية بعد اكتمال الفحص، وسجل SHA الصحيح. لا تضع اسمك أو درجتك أو بيانات الدخول في الملفات العامة. اتبع مواعيد اليومين الرابع والخامس والقناة الخاصة التي تحددها المدربة شفهيًا لدفعتك.

راجع [دليل اليوم الخامس](../DAY5_GUIDE.md) لإنتاج `submission.csv` و`submission_manifest.json` و`project_bundle.zip`. الملف يشمل كل معرّفات التحدي مرة واحدة، والسياسة تطبق على الدفعة كاملة. لا تسميات أو مقاييس تحدٍّ مخترعة؛ لا تعدّ إنشاء ZIP إثبات تسليم.
