## What changes in v1.1.0

This candidate converts the learner journey into a full English-left / Arabic-right experience while preserving one shared executable code path.

- Bilingual readiness notebook, Days 1–5 notebooks and Notebook 99.
- Bilingual learner guides, requirements, rubric, submission guide and support documents.
- Progressive Tamweel Lite project built on free Google Colab CPU.
- XGBoost, LightGBM, bounded Optuna, honest validation, OOF probabilities, simulated decision cost, SHAP, calibration, stacking and reproducible delivery.
- Exact executable-cell SHA-256 contracts and released-reference scientific parity for Days 1–5.
- Notebook 99 structural and security validation.
- Final assessment remains **90 project points + 10 presentation points**.

## Delivery controls

The project is built in five daily stages and submitted once as one complete repository. The instructor issues the cohort deadline, private submission channel and resubmission policy in writing.

The final record includes the repository URL, immutable tag, exact commit SHA, final-check URL, presentation PDF and private receipt. A green workflow or Notebook 99 readiness result is not a grade, authenticity decision or submission receipt.

## Technical boundaries

- Free CPU path; no paid service, GPU, API key or Drive mount is required.
- Synthetic data only.
- Educational and recovery outputs cannot be submitted as personal execution evidence in assessment mode.
- The simulated decision cost `10 × FN + 1 × FP` is an instructional comparison unit, not Saudi riyals, expected credit loss or a grade deduction.
- The public challenge labels and private evaluator assets are not included in the learner repository.

## Release status

`v1.1.0` remains a controlled candidate until hosted-Colab acceptance, visual review, the private evaluator, the private submission registry, final integrity-manifest generation and coordinated portal/template release are complete.

## ما الذي يتغير في v1.1.0

يحوّل هذا المرشح رحلة المتدرب إلى تجربة كاملة: الإنجليزية في العمود الأيسر والعربية في العمود الأيمن، مع بقاء مسار كود تنفيذي واحد مشترك.

- دفتر استعداد ثنائي، ودفاتر الأيام 1–5، ودفتر 99.
- أدلة ومتطلبات وسلم تقييم ودليل تسليم ومواد دعم ثنائية اللغة.
- مشروع Tamweel Lite تراكمي يعمل على CPU المجاني في Google Colab.
- XGBoost وLightGBM وOptuna المحدود والتحقق الصادق واحتمالات OOF وتكلفة القرار التعليمية وSHAP والمعايرة والتكديس والتسليم القابل لإعادة الإنتاج.
- عقود SHA-256 دقيقة لخلايا الكود وتطابق علمي مع الإصدار المنشور للأيام 1–5.
- تحقق بنيوي وأمني لدفتر 99.
- يبقى التقييم النهائي **90 درجة للمشروع + 10 درجات للعرض**.

## ضوابط التسليم

يُبنى المشروع عبر خمس مراحل يومية، ثم يُسلّم مرة واحدة كمستودع كامل. تصدر المدربة موعد الدفعة وقناة التسليم الخاصة وسياسة إعادة التسليم كتابةً.

يتضمن السجل النهائي رابط المستودع وTag غير قابل للتغيير وCommit SHA الدقيق ورابط الفحص والعرض بصيغة PDF وإيصال الاستلام الخاص. لا تعني علامة Workflow الخضراء أو جاهزية دفتر 99 الحصول على درجة أو إثبات الأصالة أو اكتمال الاستلام.

## الحدود التقنية

- مسار CPU مجاني؛ لا حاجة إلى خدمة مدفوعة أو GPU أو مفتاح API أو ربط Drive.
- البيانات اصطناعية فقط.
- لا يجوز تقديم المخرجات التعليمية أو مخرجات التعافي بوصفها دليل تنفيذ شخصي داخل وضع التقييم.
- تكلفة القرار التعليمية `10 × FN + 1 × FP` وحدة تعليمية للمقارنة، وليست ريالات سعودية أو خسارة ائتمانية متوقعة أو خصمًا من الدرجة.
- لا يتضمن مستودع المتدرب تسميات التحدي أو أصول المقيم الخاص.

## حالة الإصدار

يبقى `v1.1.0` مرشحًا محكومًا حتى يكتمل اختبار Colab المستضاف والمراجعة البصرية والمقيم الخاص وسجل التسليم الخاص وتوليد Manifest النزاهة النهائي وإطلاق البوابة والقالب بالتزامن.
